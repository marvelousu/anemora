### 2.1 範囲・移動制限 (土砂封鎖を視界誘導に統一)

| エリア | 方角 | 序章 | S1 | S2 | S3 | S4 | S5 |
|--------|------|------|----|----|----|----|----|
| Niro家 | 西 | 開放 | 戻り可 | 戻り可 | 戻り可 | 戻り可 | 戻り可 |
| 中央広場 | 中央 | 通過 | 開放 | 開放 | 開放 | 開放 | 開放 |
| 図書館跡 | 北 | 視界誘導 | メイン | 戻り可 | 戻り可 | 戻り可 | 戻り可 |
| ミア家 | 東 8m | 視界誘導 | 視界誘導 | メイン | 戻り可 | 戻り可 | 戻り可 |
| 街角 + アリア家 | 南 | 視界誘導 | 視界誘導 | 視界誘導 | メイン | 戻り可 | 戻り可 |
| カイア畑 | 南 (街と森境) | 視界誘導 | 視界誘導 | 視界誘導 | 視界誘導 | メイン | 戻り可 |
| 廃墟予兆 | 最南 (層 2 布石) | 視界誘導 | 視界誘導 | 視界誘導 | 視界誘導 | 視界誘導 | メイン |

「視界誘導」= 物理的封鎖なし、道が「見えていない」演出 (朝の影 / 並ぶ建物の輪郭で行き止まりに見える)。前進トリガーで視界が開ける (例: シーン 1 [1.G] レトのヒントで東のミア家方向の煙が見える、シーン 2 [2.F] でミアのヒント + 視界解放演出 1+5: 陽の角度 + 音の誘導 で南方面が可視化)。

### 2.2 視界解放メカニズム (1+5)

シーン進行に応じて以下を組み合わせて視界を開く:

1. **時間経過** (陽の角度): シーン 1 開始時 (朝早) → シーン 2 終了時 (午前) で陽が一段高くなり、南方面の影が薄れる、ライティング変更で表現
5. **音の誘導**: 中央広場に戻ると南方面から微かな街角の音 (風 / 鳥 / 遠くの足音) が聞こえる、Zone1AudioController で実装

旧設計の物理封鎖 (土砂・崩れ・霧) は **不採用**。立て札 / 立入禁止 UI も出さない。

## 4. 序章 マップ詳細

### 4.1 Niro家 内部

- スケール目安: 5m × 4m 1部屋
- 配置:
  - ベッド (北西) — 起床位置
  - 玄関ドア (南壁中央) — 時の筆発見位置
  - 木のテーブル + 椅子 (中央)
  - 棚 (東壁) — 「(...誰か、いた気がする)」トリガー
  - 窓 (北壁) — 朝日差し込み、外光源
- インタラクト:
  - [O.A] ベッド: 起床オート演出
  - [O.B] 棚: 「(...静か)(...誰か、いた気がする)(...ここに)」3点
  - [O.C] 玄関ドア前: 時の筆発見オート、その場で1回しゃがむ
- 動線: ベッド → 自由探索 → 玄関 (玄関に近づくとオート発動)

### 4.2 玄関〜中央広場〜図書館跡入口

- 距離目安: Niro家玄関 → 広場入口 約4m → 広場中央 → 図書館跡アーチ 約5m
- 配置:
  - 広場井戸 (中央)
  - 木のベンチ (西)
  - 老人NPC1 (ベンチ脇に立つ、無言、視線だけ向ける)
  - 図書館跡アーチ (北側)、ろうそく光が漏れる
- 視覚誘導:
  - 図書館跡からの暖色のろうそく光が画面奥で揺れる
  - 老人NPCの視線がアーチを見ている
- 移動制限 (視界誘導で統一、土砂・物理封鎖は不採用):
  - ミア家方向 (東 8m): 視界誘導で「道が見えない」(立て札・物理封鎖なし)
  - 南方面: 視界誘導で「行き止まりに見える」(朝の影 + 並ぶ建物の輪郭)
  - 北方面: 図書館跡のみ、北方面に他の道はない (旧版「廃墟予兆 = 北道」は不採用、シーン 5 廃墟予兆は南端へ移動)

## 5. シーン1: 図書館跡 マップ詳細

### 5.1 図書館跡 外観 + 内部

- スケール: 入口アーチから内部最奥まで 約8m
- 配置:
  - アーチ入口 (南)
  - ろうそく台 × 3 (両壁)
  - 崩れた書架 × 4 (左右壁沿い)
  - レト机 (奥中央) — レト初対面位置
  - 床に散らばった本のページ
- インタラクト:
  - [1.A] 接近: アーチくぐりオート、ろうそく光カメラ
  - [1.B] レト机前: 初対面会話「見ない顔ですね」
  - [1.C] レト机上の空き場所: 時の筆チュートリアル発動 (赤シンボル)
  - [1.D] 過去図書館 (時の窓越し): アリア遠景配置のみ、母娘会話は無し (S3 で出す)
  - [1.E] 現在に戻ると本が机上に出現
  - [1.F] レト再会話: ミア家ヒント
- 動線:
  - アーチ → 床ページの誘導 → レト机 → 時の筆発動 → レト → 退出
  - 退出時、外で煙突の煙 (ミア家方向) が見えるカメラ寄り
- 移動制限:
  - 過去図書館は遠景レイヤーで歩けない (時の窓越し)

### 5.2 過去図書館 (時の窓越しレイヤー)

- 表示のみ、操作不可
- 配置:
  - 棚に本がぎっしり並ぶ
  - アリア (12-15、商人の娘) が遠景で本を読んでいる
  - 他の住人2-3人が背景で動く (シルエット可)
- 注意: アリアと母 (カーラ) の親密シーンは S3 街角で出す。S1 はアリア単独遠景に留める。

## 6. シーン2: ミア家 マップ詳細

### 6.1 ミア家 外観

- 中央広場の東 約8m
- 配置:
  - 木造一軒家、屋根に煙突 (煙が出ている)
  - 玄関前に職人道具 (はさみ、布の山)
  - 玄関戸は半開き
- インタラクト:
  - [2.A] アプローチ: 煙突カメラ寄り、道具で職人感を匂わせる
  - [2.B] 玄関前: ミアと出会う「あら、見ない顔ね」、家へ招き入れオート

### 6.2 ミア家 内部

- スケール: 6m × 5m
- 配置:
  - 中央: テーブル + 椅子4脚
  - 西壁: 作業場 (ハサミ、布、ミシン的なもの)
  - 北壁: 棚 (種の包みが置いてある)
  - 東壁: 暖炉 (火が小さく揺れる)
  - 南壁: 玄関戸
- インタラクト (主 handover §8 v1.2 と整合):
  - [2.C] 家具調査: 暖炉「(...火)」/ 作業場「(...糸)」/ 棚「(...種?)」/ テーブル「(...縫いかけの布)」
  - [2.D] テーブル: ミアの語り「街もね、最近、静かになって」「縫いかけのものが、いくつもあってね」(短縮、物忘れ言及は [2.E] に集約)
  - [2.E] 種受け取り: インベントリ追加 SE / UI、種袋 (布袋に紐、暖色) を渡す
  - [2.F] 玄関: 出発、視界解放演出 (1+5: 陽の角度 + 音の誘導)
    - ミア家を出ると陽が一段高くなる (ライティング変更)
    - 中央広場に到達 → 南方面から微かな音 (風 / 鳥 / 遠くの足音)
    - 南方面の道が陽に照らされて光って見える
    - **土砂封鎖は不採用**、視界誘導に統一
- 動線: 玄関 → テーブル(自動) → 棚 → 玄関 → 中央広場 → 南方面 (視界解放後)
- ※ 詳細 dialogue は主 handover `chapter1_s1_s2_handover_2026-05-08.md` §8 v1 final 参照

## 8. 動線設計の意図 (横断ルール)

| 要素 | 方針 |
|------|------|
| 視覚誘導 | 光源 / 煙 / NPC視線 で次の場所を匂わせる、矢印UIは出さない |
| 移動制限 | 視界誘導 (道が見えない演出 + 段階的視界解放) で統一、土砂・崩れ・霧などの物理封鎖は **不採用**、立入禁止 UI も出さない |
| 自動演出 | 含み演出はオート (起床・初対面・時の筆発動) |
| 操作演出 | 調査と移動はプレイヤー操作、戻れる場所は戻れる |
| 異物原則 | Niro は違和感を感じる演出を最小に、住人側のリアクションで匂わせる |
| 時の窓 | ホットスポット型、アイコンは控えめに、近接で淡く光る |
