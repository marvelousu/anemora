## 4. ドア前で時の筆を取り出す演出

**発火**: 主人公がドア (`Door_House.prefab`) の Trigger collider に入った時。`STAGE3_TBD_RESOLUTION.md` §3.2 で確定:

> **ドアの前で家を出るとき、ポケットから取り出して気づく** (確定)。
> ベッドから起き上がるタイミングは「主人公の立ち姿確認」「家の確認」「操作の試行」など他の感情で混雑するため、ドア前で発見が最適。家を出る = 世界に踏み出す = 時の筆を握って立つ、の象徴的接続。

### 4.1 演出の構造

1. プレイヤーがドアに近づく → Trigger 発火
2. 主人公の歩みが一瞬止まる (Animator pause 0.5s)
3. ポケットを探る or 服の中から何かを取り出すアニメ (Animator state)
4. テキスト 1 行表示
5. 時の筆 (Item) を持つアニメ → 通常の歩行可能状態へ復帰
6. ドアを開けて外に出る

### 4.2 テキスト候補

| 案 | テキスト | 質感 |
|---|---|---|
| A | (これは…) | 主人公が認識していない反応、シンプル |
| B | (ポケットに、何か入っている) | より客観的、距離感がある |
| C | (持っていた、はずだ) | 「元から持っていた」設定の伏線、考察余地あり |
| D | 時の筆。 | 主人公が即座に名前を認識、能動的 |
| E | (これがあれば、何かが見えるかもしれない) | チュートリアル的、ガイド色強め |

### 4.3 推奨

**B** (ポケットに、何か入っている) を v0 採用。

- 「時の筆」という名称を即座に出さない (プレイヤーが街で実際に使う段階で UI に名前が出る)
- 主人公の認識との距離感を保つ (silent protagonist と整合)
- 異物原則: 主人公がこの遺物を「当たり前に知っている」素振りを見せると、最終盤の反転 (= 主人公だけが使える) が弱まる

C は考察余地が魅力的だが、序盤に置くには情報密度が高い。Stage 3 試作で B / C を切替えてユーザー判断。

```csharp
gameSettings.tutorial.timewriter_discover_text_variant = "B";  // "A" | "B" | "C" | "D" | "E"
```
