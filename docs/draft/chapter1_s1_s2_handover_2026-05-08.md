### 3.6 時の窓モード仕様 v3.2 (2026-05-09 確定)

「時の窓 = 部分的な時代変化」コンセプトを維持するため、内部範囲指定モードで統一:

| 場所 | 時の窓モード | 過去/未来 あり | 過去/未来 なし |
|---|---|---|---|
| **屋外** (街角、カイア畑、中央広場) | 範囲指定、Niro 窓内 | 過去/未来の景色 | 地面 / 自然 |
| **建物 (現在も入れる)** (Niro 家、ミア家) | 内部に入って範囲指定、Niro 窓内 | 過去/未来マップ | 真っ暗 / 別演出 |
| **建物 (廃墟)** (アリア家) | **入れる仕様にする** (戸が朽ちて半開き、入れる)、内部で範囲指定、Niro 窓内 | 過去/未来マップ | 真っ暗 / 別演出 |
| **大きな建物** (図書館跡) | 内部で範囲指定 (建物全体には窓届かない、サイズ制限) | 過去/未来内部 (一部) | 真っ暗 / 別演出 |
| **特殊ギミック (例外)** | ドアに時の窓 → 過去/未来マップ全体 (パズル要素として一部箇所のみ採用) | — | — |

#### 設計原則

- 過去/未来は対称、両者に違いなし
- Niro が窓内に入って歩ける、過去/未来 NPC は気付かない (異物原則維持、設定 A 延長)
- 過去/未来 NPC の独り言 / NPC 同士の会話を Niro が聴ける、Niro が話しかけても反応しない
- 廃墟も基本「入れる」(ドアがない / 朽ちて半開き)、ドアモードは特殊ギミック扱い

#### Niro が窓内でできること (Layer 1 で許可)

- 歩く (移動)、触れる (オブジェクト操作、本を取る等)、観察する、過去/未来 NPC の会話を聴く

#### 段階的拡大 (Layer 1 → 5)

- **Layer 1 (Antela)**: 個人レベルの干渉、痕跡も個人レベル (例: 本を取る、本が現在に出現)
- **Layer 2 (シーン 4 T4)**: 空間的代償、遠地への影響 (D 香料 → C 畑)
- Layer 3-5: 構造的、唯一性、主語反転 (Story Bible 既存)

#### 旧設計 (Layer 1 観察ルール) からの変更

- 旧: Layer 1 = 観察するだけ、能動行動・因果連鎖は T4 (シーン 4) が初体験
- 新: Layer 1 から能動行動 + 痕跡可、T4 は **空間的・遠地での因果連鎖** の初体験に再定義
- 経緯: `docs/devlog/2026-05-09_chapter1_layer1_revision_and_scene3_design.md`

#### 例外: シネマティック cutscene カメラ (2026-05-10 追加)

isometric strict ルール (SPEC §7.4) は **通常プレイ中** のカメラに適用。**章クライマックス + 章終了の cutscene** では例外的に他の視点を採用可:

- 例: シーン 5 [5.D]-[5.E] = **横からの 2D side view** (cinematic、Antela 全体を地平線で見せる + 小石蹴る BF1 演出)
- 適用条件: プレイヤー操作なし (オート)、cinematic cutscene として明示
- 通常プレイのカメラとは明確に区別 (例外箇所は各シーン詳細で明示)

#### 例外: ストーリー上の見せ場でのオート発動 (2026-05-09 追加)

- **デフォルト**: プレイヤーが時の窓を自由に発動 (場所・サイズ・タイミング、すべてプレイヤー操作)
- **例外**: 章クライマックスや特別な瞬間ではストーリー上の確実な演出を優先して **オート発動**
  - 例: シーン 4 [4.D] T4 連鎖の発動 → 過去のカイア畑 (健康な畑 + 先祖 + ダリオ訪問) 演出を確実に見せる
  - 例: シーン 4 [4.G] 過去側 確認 → ダリオの代償の演出
- プレイヤー側の認識: 時の筆の反応 (淡い赤光) + Niro 心情で「特別な瞬間」と認識
- 自由発動と区別する目印: Niro 心情「(...筆が、反応している)」等
- ※ オート発動の例外箇所は各シーン詳細で明示する (`§7 §8 §9` で「**オート例外**」と明記)

## 5. 操作方式 (混在型、確定)

### 5.1 方針

- **含み演出 = オート** (起床 / 時の筆発見 / 章名直結 等、シーン転換とテキスト演出)
- **調査と移動 = プレイヤー操作** (家の中探索 / 街中歩行 / 建物アプローチ等)

### 5.2 動線設計粒度 (確定)

各シーンを以下の 5 軸で設計する (recovery file の user feedback「動線をしっかりと設計したい」反映):

| 軸 | 内容 |
|---|---|
| 物理配置 | GameObject の絶対座標、距離、サイズ |
| 視覚誘導 | 光源 / 色 / 動きで誘導する具体演出 |
| プレイヤー操作 | 操作可能要素 (歩行 / 調査 / 対話 / 干渉) |
| 進行トリガー | シーン進行のための必須トリガー (位置 / 操作 / 時間) |
| 移動制限 | 進めないエリアと制限解除条件 (土砂 / 鍵 / 心情等) |

各シーン詳細 (序章 + シーン 1-2) は §6-9 で 5 軸に従い記述。

## 11. Niro 演出方針 (重要、recovery user feedback 反映)

### 11.1 Niro 自身は違和感を感じない

- "(...知っている顔は、いるはず)" "(...覚えのある顔)" "(...いない)" 等は **NG** (削除済)
- "(...知っている顔)" "(...あった、はず)" まで **省略** (recovery 最新)
- ⇒ Niro 自身は知っている人がいないことに違和感を **感じない** 設定

### 11.2 周囲の反応で異物性を匂わせる

- レト「見ない顔ですね」 (シーン 1)
- ミア「あら、見ない顔ね」 (シーン 2)
- 過去 NPC は Niro を見ない / 認識しない (時の窓越しなので過去 NPC からは見えない、整合)
- ⇒ プレイヤーが **「あれ、Niro はこの街の人じゃない?」** と少しずつ気付く構造

### 11.3 旅の動機 (内面のみ、家のみで提示)

- 「**知っている顔を探す**」というぼんやりした動機
- 偽記憶設定 (家族・知人がいたような気がするが、思い出せない)
- ⇒ Niro 家の中 ([O.B]) でのみ静かに匂わせる ("(...誰か、いた気がする)" 等)
- ⇒ 街中に出てから動機を声高に出さない、Niro の内面で消える

### 11.4 Niro 家の隠し伏線 (第 1 章からのサービス、2026-05-09 追加)

#### 位置付け

- 動線通りに進めば戻らない (序章 → シーン 1 → 2 → 3 → ...)
- **あえて戻って試してみる** プレイヤー向けの隠し要素
- ちょっとした伏線として、第 4 章メイン演出への前振り

#### 演出

Niro が自分の家に戻り、内部で時の窓を発動:

| 周回 | 時間軸 | Niro 家の状態 | 提案演出 |
|---|---|---|---|
| **1 周目** | 過去 (赤) | 別の家族が住んでいた気配 + Hook | (詳細下記 B-5 specifics) |
| **2 周目** | 過去 (赤) + **未来 (青)** | 過去 = 同上 + 未来 = 廃墟 | 未来 = 砂埃、家具朽ちる、誰もいない、観測者磨耗の最終段階匂わせ |

※ 1 周目は時代選択機能なし = 赤 (過去) のみ使用 (§3.6 シンボル段階開示)。未来 (青) は **2 周目で覚醒**、Story Bible memory「2 周ループ構造」整合 (1 周目末で青覚醒 → 2 周目で実用)。

##### B-5 specifics (2026-05-10): 1 周目過去の Niro 家配置 + Hook

| 要素 | 現在 (Niro 1 人) | 過去 (別の家族の気配) |
|---|---|---|
| ベッド | 1 つ、北西 | 2 つ、北西 (大人) + 北東 (子供サイズ) |
| テーブル | 1 つ + 椅子 2 脚 | 1 つ + 椅子 4 脚 + 編み物道具 (糸玉 / 針 / 編みかけの布) |
| 棚 | 1 つ、東壁 | 2 つ、東壁 + 西壁 (料理道具 / 衣類) |
| 食器 | 1 セット | 4 セット並ぶ |
| **壁の枠 (Hook)** | **空の枠**、北壁 (窓の隣)、キャンバスだけ残る | **同じ枠に家族の絵**、3-4 人、ただし **顔が描き欠け / シルエット / にじんでいる** ← 観測者磨耗 + 偽記憶 メタ伏線 |
| 服 / 靴 / 鍋 / 編み物 | (現在になし) | 椅子に脱いだ服、靴 2 セット (子供 + 大人)、鍋使いかけ、編みかけ |

**人物気配の表現原則**: 人物そのものは描かない、**「人々が暮らしていた痕跡」を物の配置で表現**

##### Niro 心情 (2 行のみ、分散発火)

| トリガー | Niro 心情 |
|---|---|
| 内部全体を見渡す (発動直後、自動) | **"(...誰か、ここに)"** |
| **壁の枠**に近づく (Hook reaction) | **"(...顔が、見えない)"** |

##### audio (過去のみ)
- 編み物の音 (微弱、まれに、ループ)
- 食器が触れ合うかすかな音
- 暖炉の火のパチパチ音
- 子供の遠い笑い声 (ごく微弱、聞こえるか聞こえないか) ※ オプション

##### narrative 効果
- 「家族がいた」だけでなく「**誰が描かれたかも、誰が描いたかも、もう分からない**」感覚
- 観測者磨耗テーマ整合 (記憶 / 知識が薄れる)
- 第 4 章メイン演出 (「別の家族が住んでいた」確定、Story Bible §5.3.2) を弱めない (ぼかし匂わせ)
- Niro 偽記憶設定整合 (家族の顔を思い出せない = 過去の家族の顔も描かれていない)
- 第 4 章での回収余地: 「あの絵の顔」が第 4 章でどう処理されるかは別タスク (第 2 章以降設計時)

#### 設計上の意図

- 第 4 章「Niro 家の過去確認 → 別の家族が住んでいた = 偽記憶設定の確定演出」(STORY_BIBLE §5.3.2) を **弱めない**
- 第 1 章では **気配のみ、はっきり見せない** (好奇心向けサービス)
- 第 4 章で「あの違和感はこれだったのか」と回収

#### シーン 3 [3.D] アリア家との対比

- アリア家 = 過去に家族がいた、温かい (確定情報)
- Niro 家 = 過去にも家族がいた **気配** (誰?、不確定)
- → Niro 異物性の伏線、観測者磨耗テーマと連動
