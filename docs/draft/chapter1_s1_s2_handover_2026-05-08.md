### 1.4 シーン 3: 街角 + アリア家 (時の窓越し中世)

## 2. アートディレクション

### 2.1 全体トーン (HD-2D Tier 2)

- 黄昏色彩を世界全体のトーンとして敷く
- 静謐・衰退 を基調 (劇的でなく、ゆっくり、一歩ずつ)
- isometric strict カメラ (SPEC §7.4 確定)
- 動的影 + 単一方向光 + カラーグレーディング (Tier 2 範囲)

### 2.2 過去 / 現在対比

| 軸 | 過去 (中世繁栄) | 現在 (緩やかな衰退) |

| カラー | 暖色 / 高彩度 / 金色寄り | 寒色 / 低彩度 / 灰色寄り |
| ライティング | 明るい、影は柔らかい | 薄暗い、影が長い |
| 環境音 | 賑わい、市場のざわめき、子供の声 | 静寂、風の音、たまの足音 |
| NPC 密度 | 多い、動きがある | 少ない、動きが少ない |
| 建物 | 整っている、新築感 | 摩耗、ひび、苔、剥落 |

### 2.3 時の窓内表現

- 窓の境界: 過去 = 赤、現在 = 白 (PROTOTYPE_TIME_FRAME_v0.md §3.2)

## 5. 操作方式 (混在型、確定)

### 5.1 方針

- **含み演出 = オート** (起床 / 時の筆発見 / 章名直結 等、シーン転換とテキスト演出)
- **調査と移動 = プレイヤー操作** (家の中探索 / 街中歩行 / 建物アプローチ等)

### 5.2 動線設計粒度 (確定)

各シーンを以下の 5 軸で設計する (recovery file の user feedback「動線をしっかりと設計したい」反映):

| 軸 | 内容 |
|---|---|
| 物理配置 | GameObject の絶対座標、距離、サイズ |
| 視覚誘導 | 光源 / 色 / 動きで誘導する具体演出 |
| プレイヤー操作 | 操作可能要素 (歩行 / 調査 / 対話 / 干渉) |
| 進行トリガー | シーン進行のための必須トリガー (位置 / 操作 / 時間) |

## 7. シーン 1 詳細 ([1.A]-[1.H] v3 final、2026-05-09 確定、8 セクション)

### 7.1 確定要素

- 時の窓 = **設定 A** (Niro + プレイヤー UI のみ、レトには見えない)
- レト = **L-γ** 諦観 + 芯 (L-γ クライマックスは [1.C] に集約、[1.F] は深追いしない)
- 失われた本 = **B-γ** 街の記録 (公的台帳・名簿)、レトの口頭で言及のみ (現在に出現させない)
- 時の筆 = **W-β** 序章で発見、シーン 1 で初発動
- Niro 異物性伏線 = **D-β**「見ない顔ですね」のみ (本が出現しないので、レトには Niro が特別だと信じる根拠なし)
- 所要時間 = **T-β** 約 7 分 (10 分目標範囲内)
- **観察ルール整合**: Layer 1 は「観察するだけ」(STORY_BIBLE §3.2)、能動行動・因果連鎖は **T4 シーン 4 が初体験** → 過去観察後の現在変化なし
- **8 セクション構造** (旧 7 セクション → [1.C] 新設 + 旧 [1.D]-[1.F] → [1.E]-[1.G] にリナンバリング、旧 [1.G] → [1.H])

### 7.2 v3 final 流れ (8 セクション)

#### [1.A] 図書館跡 接近 (プレイヤー → オート、約 30 秒)

- 場所: 中央広場北 → 図書館跡 アーチ入口
- 演出: ろうそくの揺れる暖色光、石畳に苔、アーチに蔓植物、アーチ内側からカリカリと羽ペンで記録する音
- 操作: プレイヤー歩行 → アーチ接近でカメラがゆっくり寄る (オート切替)
- 進行トリガー: アーチ通過

#### [1.B] レト 初対面 (オート、約 1 分)

- 場所: 図書館跡 室内、レトの机
- 演出: レトが机で台帳に記録している、Niro の足音で顔を上げる
- レト (穏やか、諦観の口調):
  - 「...見ない顔ですね」 (= D-β、異物性匂わせのみ、これ以上突っ込まない)
- カメラ: レトの目線 → Niro の足元 → Niro の顔 (短いカット)
- レト:
  - 「私はレト。元、教師でした」
  - 「今は、ここで街の記録を残しています」
- レト動作: 机上の薄い帳面を軽く撫でる (自作の台帳)
- 背景: 周囲の空棚が広がる、ろうそく光が揺れる

#### [1.C] レト → 図書館の歴史 + 誘い (オート、約 2 分) **NEW**

- レト (空棚を見上げる):
  - 「ここは昔、街の記録がすべて集まる場所だった**そうです**」 ← 伝聞形 = レトも直接知らない (異物原則維持、観測者磨耗の匂わせ)
  - 「人々の名簿、家系の記録、街の決まり事…」
  - 「今では、誰も覚えていません」
- Niro 心情: "(...誰も)"
- レト:
  - 「私が書き写しているのも、聞いた話の継ぎはぎです」 ← **L-γ クライマックス**
  - 「それでも、書いておかないと、いずれ何もかもが」
  - (レト、言葉を切る)
- Niro 動作: 視線がゆっくり空棚に向く
- Niro 心情: **"(...からっぽ)"** ← ひらがな (誤読回避)、事実描写のみ (自己違和感は出さない、§11)
- レト (Niro の視線に気付く、穏やかに):
  - 「...本があった頃の話を、聞きたければ」 ← 自然な誘い、時の筆発動への架け橋
- レト: 帳面を閉じて、Niro を見る (沈黙)
- ※ レトは時の筆について何も知らない、ただ Niro が空棚に何か感じているのを察した

#### [1.D] 時の筆 発動 (オート → プレイヤー、約 1.5 分)

- Niro 心情: "(...筆)" ← 序章 [O.C] で拾った時の筆を意識
- Niro 動作: 時の筆を取り出す (オート)
- レト: 「...?」 ← 訝しげに見るが問わない (L-γ 静かな受容)
- 時の筆 反応: 空棚の方向に淡い赤光 (UI 演出、レトには見えない = **設定 A**)
- Niro 心情: "(...?)"
- チュートリアル UI 出現:
  - 「赤シンボル (過去) を選択」
  - 「ドラッグで窓を描く」
- プレイヤー操作: 赤シンボル選択 → 空棚を中心に窓描画 (チュートリアル誘導)

## 11. Niro 演出方針 (重要、recovery user feedback 反映)

### 11.1 Niro 自身は違和感を感じない

- "(...知っている顔は、いるはず)" "(...覚えのある顔)" "(...いない)" 等は **NG** (削除済)
- "(...知っている顔)" "(...あった、はず)" まで **省略** (recovery 最新)
- ⇒ Niro 自身は知っている人がいないことに違和感を **感じない** 設定

### 11.2 周囲の反応で異物性を匂わせる

- レト「見ない顔ですね」 (シーン 1)
- ミア「あら、見ない顔ね」 (シーン 2)
- 過去 NPC は Niro を見ない / 認識しない (時の窓越しなので過去 NPC からは見えない、整合)
- ⇒ プレイヤーが **「あれ、Niro はこの街の人じゃない?」** と少しずつ気付く構造

### 11.3 旅の動機 (内面のみ、家のみで提示)

- 「**知っている顔を探す**」というぼんやりした動機
- 偽記憶設定 (家族・知人がいたような気がするが、思い出せない)
- ⇒ Niro 家の中 ([O.B]) でのみ静かに匂わせる ("(...誰か、いた気がする)" 等)
- ⇒ 街中に出てから動機を声高に出さない、Niro の内面で消える
