## Selection Rationale

ADR-0003 と `docs/STAGE3_F_PLAN.md` §4.2 に合わせ、16-32 色内の制限パレットとして 24 色にした。HD-2D Tier 2 の動的影が乗る前提なので、黒を強くしすぎず、暗部は `Charcoal Ink` / `Deep Shadow` / `Warm Shadow` の 3 段階に分けた。

主人公側は `Worn Brown` / `Old Leather` / `Soft Beige` / `Pale Cloth` / `Dark Trouser` を中心に、worn brown jacket、soft beige inner cloth、dark trousers が同じ画面で沈みすぎない明度差を確保した。

街と環境装飾は `Weathered Stone` 系、`Moss Grey` 系、`Fallen Leaf` 系を分けた。衰退 / 静謐を優先し、鮮やかな緑や彩度の高い紅葉色は避けている。建物は weathered stone / faded wood の範囲に収め、異物原則に反する強い発光色や記号的な異界色は入れていない。

UI 系は `UI Text` / `UI Muted Text` / `UI Frame` を用意した。本文は背景から浮かせるため暖かい淡色、枠は木・石とも接続しやすい鈍い金茶にしている。`Quiet Accent` は警告や選択色の最小アクセント、`Memory Blue Grey` は時間・記憶系の補助色として入れたが、常用しない。

## Review Points

- 主人公の服色が地味すぎてシルエットを失わないか
- 街・室内・UI が同じ茶灰色に寄りすぎないか
- `Quiet Accent` と `Memory Blue Grey` が異物原則を破らず、必要な UI 状態差だけを出せるか
- HD-2D Tier 2 の動的影下で `Deep Shadow` / `Warm Shadow` が潰れないか
