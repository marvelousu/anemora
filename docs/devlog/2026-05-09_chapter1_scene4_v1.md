# Chapter 1 シーン 4 v1 動線骨格 + エリュトリア + カイア設定 + 仕様 v3.2 例外追記 (2026-05-09)

## 背景

シーン 1 v4 + シーン 3 v3 + シーン 4 T4 再定義 (commit 57080ef、Layer 1 仕様改訂) を受けて、シーン 4「カイア畑」の動線詳細設計に入る。

シーン 4 = T4 連鎖の核心、章クライマックス Z 第 1 段階「個人レベル干渉は局所、空間的・大規模干渉は遠地に代償を生む」気付き。

## 確定事項

### 1. エリュトリアの正体 (シーン 3-4 連動キーワード)

- **E-1: 失われた交易相手の街**
- 過去に Antela と交易していた街、現在は廃墟 / 道途絶 / 誰も覚えていない
- 観測者磨耗テーマと整合、第 2-3 章 (衰退) で深掘り余地

### 2. シーン 4 でのエリュトリア連動

- **EC-2: 香料連動**
- ダリオの香料 = エリュトリア由来
- T4 干渉でカイア畑に間接連動 (空間的代償の説得力↑)
- 第 1 章では伏線止め、深い回収は第 2-3 章

### 3. カイア (C) 設定

| 項目 | 内容 |
|---|---|
| 年齢 | 25-30 |
| 職業 | 街と森境のナッツ農家 |
| 家族 | **一人暮らし** (※衰退の象徴の一部、表現は出さない) |
| 性格 | 観察力ある、寡黙寄り、畑に集中、真面目 |
| 街との繋がり | 仕事限定 (種 / 道具を取りに行く程度、特に親しい人なし) |
| ミアとの差別化 | 面倒見の良さ vs 畑中心、明確に分ける |

### 4. 過去のカイア畑の所有者

- **カイアの先祖** (祖父 / 父 / 等)
- **設計上のみ、ストーリーには触れない** (小ネタ的)
- 表現: シルエット or 背景人物、固有名なし
- 他の章での会話で「昔から畑をしていた家系」と匂わせる余地

### 5. 仕様 v3.2 例外: ストーリー上の見せ場でのオート発動

- 通常はプレイヤーが時の窓を自由に発動 (デフォルト C プレイヤー発動)
- 章クライマックスや特別な瞬間 (= シーン 4 [4.D] T4 連鎖の発動) ではストーリー上の確実な演出を優先して **オート発動**
- プレイヤーは時の筆の反応 (赤光) と Niro 心情で「特別な瞬間」と認識

## シーン 4 v1 動線骨格 (9 セクション [4.A]-[4.I]、約 8-10 分)

### [4.A] カイア畑 接近 (プレイヤー操作 + 視覚誘導、約 30 秒)
- 場所: 街角 → 街と森の境を越える → カイア畑
- 物理配置: 緩やかな斜面 (北側 = 街方向、南側 = 森方向)、ナッツの木 7-10 本、中央に作業小屋、井戸
- Niro 心情: "(...畑)" / "(...森?)"
- 進行: カイア畑入口接近で [4.B]

### [4.B] カイア 出会い + 種を渡す (オート、約 1.5 分)
- カイアが畑作業中 (枝を見ている、観察力ある仕草)
- カイアが Niro に気付く
- カイア (寡黙寄り):
  - 「あら、誰?」
- Niro が無言で種袋を渡す
- カイア:
  - 「これ、ミアさんから?」
  - 「ありがとう」
- カイア動作: 種袋を受け取る、軽く中を確認
- カイア:
  - 「最近、忙しくて取りに行けてなくて」
  - 「ちょうど、種を蒔きたかったの」
- カイア (畑の異変を匂わせる、観察力ある描写):
  - 「最近、木の調子が悪くてね」
  - 「葉の色が、少し変で」
- ※ ミアと差別化: 寡黙、畑中心、自分の世界に集中

### [4.C] 畑の調査 + 異変発見 (プレイヤー操作 + 調査、約 1 分)
- Niro が畑を見回る
- 異変ポイント (3 箇所):
  - 1-2 本の木が枯れかけ (葉が黄色い、Niro 心情「(...枯れかけ)」)
  - 地面に早く落ちたナッツ (Niro 心情「(...落ちたナッツ)」)
  - 一部の土が変色 (Niro 心情「(...土?)」)
- Niro 調査心情で違和感を表現
- 進行: 畑全体を一通り見終わると [4.D]

### [4.D] 時の窓発動 → 過去のカイア畑 (**オート例外**、約 1 分)
- Niro が手元の時の筆を見る → 時の筆が淡く赤光 (反応、ストーリー上の特別な瞬間)
- Niro 心情: "(...筆が、反応している)"
- **オート発動**: 時の窓が自動的に開く
- 過去のカイア畑が浮かぶ:
  - 賑やかな畑 (緑豊か、健康な木、整った土)
  - **カイアの先祖** (シルエット、固有名なし) が作業中
  - **ダリオ訪問**、香料を渡す動作 (色とりどりの瓶、エリュトリア連動)
  - 暖色トーン (シーン 3 [3.C] と同じ過去演出)
- Niro 心情:
  - "(...あの男、香料?)" ← シーン 3 [3.C] のダリオ認識
  - "(...エリュトリアの…)" ← 連動キーワード回収
- ※ オート発動は仕様 v3.2 例外 (handover §3.6 追記)

### [4.E] ダリオの香料に干渉 (**プレイヤー操作**、約 1.5 分)
- プレイヤー操作: Niro が窓内に入る (歩く)
- 過去のカイア畑を歩ける、ダリオの香料に近づく
- プレイヤー操作: 香料に触れる → **倒す or 取る** (1 回の干渉)
- 過去 NPC は気付かない (異物原則)、香料が「ひとりでに」動く
- ダリオ「!?」と独り言で驚く: 「なに?」「あの香料が…」
- 先祖 (シルエット) は淡々と作業を続ける
- Niro 心情: "(...動かした)"

### [4.F] 現在に戻る → カイア畑の変化 (**痕跡可視化**、約 1.5 分)
- Niro が時の窓を閉じる、現在のカイア畑に戻る
- カイア畑が **変化** (異変悪化):
  - 枯れかけの木が **完全に枯れる**
  - 大量にナッツが **落ちる**
  - 土の色が広範囲で **変わる**
- カイア反応 (寡黙だが驚き、観察力ある描写):
  - 「な、なに!?」
  - 「木が…ナッツが…」
  - 「これは…分からない」(真面目に分析、答え出ない)
- カイア動作: 畑を駆け回って異変を確認
- Niro 心情: "(...変わった?)" / "(...自分の?)"

### [4.G] 過去側 確認 → ダリオの代償 (**オート、約 1 分**)
- Niro が再び時の窓発動 (オート、続けてストーリー上の演出)
- 過去のカイア畑が浮かぶ
- ダリオが香料を失って困っている
- ダリオ独り言:
  - 「なに? あの香料が…」
  - 「これは…」
- 先祖 (シルエット) が首を傾げる、ダリオが頭を抱える
- Niro 心情: "(...自分が、これを?)"

### [4.H] Z 第 1 段階 気付き確定 (オート、約 1 分)
- Niro が過去・現在を見比べる
- カメラ: 過去ダリオの困った姿 → 現在カイア畑の変化 → Niro
- Niro 心情:
  - "(...遠くまで)"
  - "(...連鎖)"
  - "(...代償を生む)"
- カイア (寡黙、観察力):
  - 「あなた…大丈夫?」 ← Niro の様子に気付く程度、深追いしない
  - ※ 異物原則維持: カイアは Niro 異質性に踏み込まない
- ※ 章クライマックス Z 第 1 段階 = この気付き

### [4.I] シーン 5 への動線 (プレイヤー操作 + 視覚誘導、約 30 秒)
- 場所: カイア畑 → さらに南方面 (廃墟予兆 = シーン 5)
- 視覚誘導: さらに南へ続く道、街と森の境を越えた先の荒れ地
- Niro 心情: "(...もう少し、見てみよう)"
- 操作: プレイヤー歩行
- 進行: 廃墟予兆エリアに踏み込むとシーン 5 へ
