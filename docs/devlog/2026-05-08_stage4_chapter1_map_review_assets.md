# Stage 4 Chapter 1 Map Review Assets

Date: 2026-05-08
Branch: `codex/stage4-graphics-foundation-20260508`

## Scope

This pass adds a review-only Chapter 1 map and environment-density FBX batch for the latest proposal D five-scene structure, then imports that batch plus the 2026-05-09 close-density / DetailKit extension into generated URP Lit materials, 30 prefabs, and a prefab review capture. It does not edit or save a production Unity scene.

The priority was to make the still-loose S3-S5 areas tangible at real scale while preserving the already fixed S0-S2 constraints:

- S3 street corner plus Aria house: Current ruined street and half-collapsed house, Past market street and warm Aria/Karla home, with two planar time-window hotspot read positions and a subtle BF1 small-stone position.
- S4 Kaia field: south-road arrival, 7-10 nut trees, work shed, field rows, Kaia hand-in line, Dario spice-merchant Past read, and Current anomaly points.
- S5 north road / ruin omen: fogged road into quiet ruin plaza, 3-4 collapsed shells, no Chapter 2 robot reveal.
- S0-S2 support: Niro house interior, library Current/Past interiors, and Mia house interior with the fixed furniture beats.

## Caveats

- This is a review-layout and asset-density batch, not final authored production art.
- Materials are generated grouped URP Lit review controls with 256px atlas-derived base textures and 26 atlas-derived normal textures. They are still provisional because the current FBX import remains material-slot driven rather than atlas-UV driven.
- Time-window positions are represented as thin planar visual read points and ground/window traces only. They are not thick gates or physical openings.
- NPC invisibility for time windows remains a runtime/design rule recorded in the manifest; it is not implemented by these static FBX files.
