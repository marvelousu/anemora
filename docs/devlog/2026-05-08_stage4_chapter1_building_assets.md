# Stage 4 Chapter 1 Building Assets

Date: 2026-05-08
Branch: `codex/stage4-graphics-foundation-20260508`

## Scope

This pass adds a first procedural building batch for Chapter 1 / Antela beyond the Stage 3 Zone1 starter set. It now uses the latest 2026-05-08 Chapter 1 draft handovers as the map source of truth, especially `docs/draft/chapter1_map_handover_2026-05-08.md` and `docs/draft/chapter1_s1_s2_handover_2026-05-08.md`.

The goal is to support the Chapter 1 scene beats without locking the production first-map scene yet:

- Scene 1, library: `Library_Active_Past`, an active public-library counterpart to the existing `Library_Ruin`.
- Scene 2 / 3 support: `ResidentA_MerchantHouse_Past` and `ResidentA_MerchantHouse_Current` remain the Aria / Karla house pair for the street-corner sequence, while Mia house is represented in the route overview until a dedicated model batch lands.
- Scene 3, Antela street corner: `Antela_Rowhouse_Corner`, a reusable street-density facade module.
- Turning point, Resident_D spice chain: `Merchant_Stall_Spice_Past` and `Merchant_Stall_Closed_Current`.

## Caveats

- No production scene edit was made. The prefab review capture helper uses a temporary unsaved scene when run from Unity.
- The Antela density and cinematic reviews use temporary unsaved scenes with generated floor / backdrop / lighting / character-placement context. They are review targets, not production scene changes.
- The route overview is also a review target. It intentionally uses simplified massing for the latest five-scene spatial read and does not lock final building meshes, camera composition, or production scene placement.
- The close scene beat review is a visual direction tool, not production placement. Roof geometry and material normals have been improved, but some panels still expose the limitation of simplified blockout silhouettes; final DQ3R-class quality needs higher-information authored building meshes / roof profiles and final character sheets.
- These are procedural greybox-to-draft assets for first-map scale and scene-beat support. They are not final authored production meshes.
- The procedural base/normal textures only break up flat color and lighting response; final DQ3R-class assets still need authored texture work or stronger source meshes.
