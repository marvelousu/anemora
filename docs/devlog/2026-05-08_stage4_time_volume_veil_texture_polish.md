# Stage 4 time-volume veil texture polish

Date: 2026-05-08
Scope: GFX-1 Portal / stencil visual polish
Branch: `codex/stage4-graphics-foundation-20260508`

## Summary

The time-volume veil shader now adds subtle procedural grain and a light vertical fade. The intent is to reduce the flat transparent-panel read while keeping the existing blue/gold portal direction, camera, gameplay ordering, and production scene lighting unchanged.

## Changes

- `Assets/Art/Materials/Portal/TimeVolumeVeil.shader`
  - Adds `_GrainScale`, `_GrainStrength`, and `_VerticalFade`.
  - Uses deterministic world-space cell noise for small alpha variation.
  - Applies a mild object-space vertical fade to reduce the uniform side-wall look.
  - Keeps the existing edge color, band wave, alpha blend, ZWrite Off, ZTest LEqual, and two-sided transparent setup.

- `Assets/Art/Materials/Portal/TimeVolume_SpaceVeil.mat`
  - Sets `_GrainScale` to `18`.
  - Sets `_GrainStrength` to `0.055`.
  - Sets `_VerticalFade` to `0.25`.

- `Assets/Tests/EditMode/GraphicsFoundationAssetTests.cs`
  - Extends the veil material guard to require the grain and vertical-fade properties.
  - Keeps bounds conservative: grain strength <= `0.12`, vertical fade <= `0.5`.
