# 2026-05-05 TMP Japanese Atlas v0 Draft

## Status

Draft. ADR-0007 / ADR-0008 §3.1 の事前生成 Atlas 方針に従い、日本語 TMP Font Asset v0 を作成した。フォントの最終採用は、商用可否だけでなく絵柄整合のユーザー判断待ち。

## Font Candidate

暫定採用: 美咲ゴシック (`misaki_gothic.ttf`)。

理由:

- 8x8 系の日本語ピクセルフォントで、ADR-0008 の「8x8 - 12x12 程度のビットマップ系を優先」に合う
- TTF 版にアウトラインと埋め込みビットマップが含まれる
- 同梱 `misaki.txt` に商用/非商用を問わない自由利用・複製・再配布可、改変可、無保証の記載あり
- `docs/legal/asset_ledger.md` §1.2 / §2.5 に記録済み

Source:

- `https://littlelimit.net/misaki.htm`
- downloaded archive: `art/_intermediate/fonts/misaki_ttf_2021-05-05.zip`

## Atlas Settings

- Unity: 6000.3.14f1
- TMP / uGUI: `com.unity.ugui`
- Source font: `Assets/UI/Localization/Fonts/ThirdParty/misaki_gothic.ttf`
- Requested characters: 6,734
- Missing characters: 70
- Atlas size: 4096x4096
- Render mode: SDF
- Sampling point size: 16
- Padding: 1
- Population mode after bake: Static
- Atlas texture format: Alpha8

The character set is generated by `Assets/Editor/AnemoraTmpJapaneseAtlasBuilder.cs`: JIS 第1・第2水準相当の Shift_JIS kanji rows 16-84 plus hiragana, katakana, full-width ASCII forms, Japanese punctuation, and common dashes/quotes.

## Size Measurement

Measured files:

- `Anemora_JP.asset`: 3,023,626 bytes (約 2.88 MiB)
- `Anemora_JP_Atlas.asset`: 33,555,475 bytes (約 32.00 MiB serialized asset)
- `misaki_gothic.ttf`: 1,171,204 bytes (約 1.12 MiB)

Runtime texture estimate:

- 4096 x 4096 x Alpha8 = 16,777,216 bytes = 16.0 MiB VRAM
- Against TOM VRAM 2 GiB: 16.0 MiB is about 0.78%

Conclusion: v0 Atlas texture itself is acceptable under the 2GB VRAM constraint, but UI scene + URP + other textures must still be checked on TOM. The serialized `.asset` is larger than runtime Alpha8 VRAM because it stores Unity asset data.

## Caveats

- 70 requested characters were missing from 美咲ゴシック or failed to bake. This is acceptable for v0 draft but must be checked against real String Tables before Stage 4.
- The current source font is a candidate, not final art direction. User review is required before locking.
- Batch generation used a temporary project because the main Anemora project was already open in Unity.
