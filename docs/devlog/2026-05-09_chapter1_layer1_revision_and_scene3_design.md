# Chapter 1 Layer 1 仕様改訂 + シーン 3 v3 設計 + シーン 4 T4 再定義 (2026-05-09)

## 背景

シーン 3「街角 + アリア家」の動線詳細設計を進める過程で、時の窓の仕様について複数の重要な見直しが発生:

1. **時の窓の絵的体験**: 旧仕様 (覗き穴 + クリック干渉のみ) では絵的に手抜きに見える → Niro が窓内に入って歩ける仕様へ
2. **Layer 1 観察ルールの撤廃**: シーン 1 [1.F] 本出現削除 (2026-05-09 v3 final 確定) の根拠だったが、ユーザー再考により撤廃 → Layer 1 から干渉 + 痕跡可
3. **建物と時の窓の関係**: ドアモードのトレードオフ (効率的プレイ問題) を経て、内部範囲指定で統一する仕様 v3.2 へ

これに伴いシーン 1 v3 final → v4 へ、シーン 3 v3 確定、シーン 4 T4 再定義、Niro 家の隠し伏線追加。

## 仕様 v3.2: 時の窓モード (内部範囲指定で統一)

| 場所 | 時の窓モード |
|---|---|
| **屋外** (街角、カイア畑、中央広場) | 範囲指定、Niro 窓内 |
| **建物 (現在も入れる)** (Niro 家、ミア家) | 内部に入って範囲指定、Niro 窓内 |
| **建物 (廃墟)** (アリア家) | **入れる仕様にする** (ドアがない / 朽ちて半開き、入れる)、内部で範囲指定、Niro 窓内 |
| **大きな建物** (図書館跡) | 内部で範囲指定 (建物全体には窓届かない、サイズ制限) |
| **特殊ギミック (例外)** | ドアに時の窓 → 過去/未来マップ全体 (パズル要素として一部箇所のみ採用) |

### 設計原則
- 「時の窓 = 部分的な時代変化」コンセプトを維持
- 過去/未来は対称、両者に違いなし
- Niro が窓内に入って歩ける、過去/未来 NPC は気付かない (異物原則)
- 過去/未来 NPC の独り言 / NPC 同士の会話を Niro が聴ける、Niro が話しかけても反応しない

### Niro が窓内でできること (Layer 1 で許可)
- 歩く (移動)
- 触れる (オブジェクト操作、本を取る等)
- 観察する
- 過去/未来 NPC の会話を聴く

### 段階的拡大 (Layer 1 → 5)
- **Layer 1**: 個人レベルの干渉、痕跡も個人レベル (本を取る、本が現在に出現)
- **Layer 2 (シーン 4 T4)**: 空間的代償、遠地への影響 (D 香料 → C 畑)
- Layer 3-5: 構造的、唯一性、主語反転 (Story Bible 既存)

## Layer 1 観察ルール撤廃の経緯

### 旧設計 (Story Bible §3.2)
- 「Layer 1 = 観察するだけ、赤(過去)・白(現在)シンボルのみ」
- 能動行動・因果連鎖は T4 (シーン 4) が初体験

### 撤廃の理由
- ユーザー再考: 「Layer 1 で触れられない設計の意図が分からない」
- シーン 3 設計で時の窓の絵的体験を強化する過程で、能動行動を Layer 1 から許可した方が自然と判断
- 「観察だけで本が出現」(旧 [1.E] の問題) と「能動的に取って痕跡」(新仕様) は別物、新仕様ならコンセプト違反にならない

### T4 の再定義
- 旧: 第 1 章で **初の能動行動・因果連鎖** 体験
- 新: **空間的・遠地での大規模因果連鎖の初体験** (D 香料 → C 畑、過去から現在の遠地へ影響)

シーン 1 (個人レベル: 本を取る → 同じ場所に痕跡) と シーン 4 T4 (空間的: 遠地に影響) で性質が分かれる構造を維持。

## シーン 3 v3 動線骨格 (確定)

### [3.A] 街角 接近 (約 30 秒)
- 中央広場 → 南方面 → 街角入口
- 寂れた木造建物 3-4 棟、空の屋台 (市場跡)
- Niro 心情: "(...静か)" / "(...店、跡)"

### [3.B] 街角 現在の様子 + 時の窓発動誘導 (約 1.5 分)
- 物理配置: 市場跡 (空の屋台) / 寂れた住居 / アリア家 (戸が朽ちて半開き、入れる)
- 時の窓発動誘導 (シーン 3 限定の説明的演出):
  - 屋台に近づく → 淡い赤光 + Niro 心情「(...ここで、何かが)」「(...試したい)」
  - アリア家入口に近づく → 入口の暗さに淡い赤光 + Niro 心情「(...誰の家?)」「(...見てみよう)」
- ※ シーン 3 = プレイヤーが自分から重要ポイントに時の窓を使う **初の機会**、Niro 反応 + 光誘導で促す

### [3.C] 時の窓: 街角の中世市場 (屋外範囲指定モード、約 2-2.5 分)
- 場所: 街角の市場跡で時の窓発動
- Niro が窓内に入って市場の中を歩ける、過去 NPC は気付かない
- 過去 NPC:
  - **ダリオ (D)** (40 代、旅商人 / 香料商): 屋台で **香料** を並べる、客と話す ← シーン 4 T4 触媒
    - ダリオ独り言: 「今日のヤツは特に良い」「香りが立つ」
    - 客との対話: 「これは**エリュトリア**の新茶葉、よく合うよ」 ← 伏線キーワード
  - **カイロ (K)** (年齢不問、楽器奏者・詩人): 楽器を奏でて、人だかり、歌う
  - **ルナ (L)** (5-10、子供): 子供たち (背景シルエット数名) と遊ぶ、笑い声
  - 背景: 名無し住人多数 (商談 / 買い物 / 立ち話)
- Niro 心情:
  - "(...賑やか)"
  - "(...あの男、香料?)" ← シーン 4 T4 で「あれだ」と気付く構造
  - "(...エリュトリア)" ← 聴いた言葉、後の伏線回収
  - "(...音楽)" / "(...子供たち)"

### [3.D] 時の窓: アリア家 過去観察 (内部範囲指定モード、約 1.5-2 分)
- **現在のアリア家**: 戸が朽ちて半開き、**入れる** (空洞、朽ちた家具が散らばる)
- Niro が現在のアリア家に **入る**
- 内部で時の窓発動 (赤シンボル) → 内部全体に大きな時の窓 (小さな建物なのでサイズ制限内でほぼ全体カバー)
- 過去アリア家内部が浮かび上がる:
  - 暖色の灯り、整った家具、商家らしい棚 (商品サンプル: 茶葉、香料、布)
  - 本棚 (商家の家計簿 / 在庫帳)
- Niro が窓内に入って過去アリア家内部を歩ける
- 過去 NPC:
  - **アリア (A)** (12-15、商家の娘): カーラに **商売** を教わっている (C-4 商売教え)
  - **カーラ (J)** (アリアの母、商家女主人): アリアに商売を教える
- 商売教え dialogue:
  - カーラ「これは沖の岸からの茶葉、こちらは山のお茶」
  - カーラ「よく見て、色が違うでしょう」
  - アリア「うん、こっちのほうが濃い」
  - カーラ「お父さんが言うには、**エリュトリア**では…」 ← ダリオの言葉と連動

  - "(...母と子)"
  - "(...あの子、図書館で)" ← シーン 1 [1.E] アリア遠景認識との接続 (Niro が窓内で近くで見たアリアと同一人物?)
  - "(...商売、教えている)"

  - "(...笑っている)" / "(...ここで)"

## シーン 4 T4 再定義 (handover §9.2)

### 旧位置付け
> 章クライマックス Z 第 1 段階: 「自分の介入は代償を伴う、しかも遠くに連鎖する」気付き = A 軸 (因果連鎖) **最初の体験**

### 新位置付け
- T4 = **空間的・遠地での大規模因果連鎖の初体験**
- シーン 1 (個人レベル痕跡: 本を取る → 同じ場所に出現) との **差別化**:
  - シーン 1: 過去 → 現在の **同所** に痕跡 (図書館で本を取る → 同じ図書館の机)
  - シーン 4: 過去 → 現在の **遠地** に痕跡 (中央集落のダリオ → 街と森の境のカイア畑)
- 章クライマックス Z 第 1 段階: 「個人レベルの干渉は局所だが、空間的・大規模な干渉は **遠地に代償を生む**」気付き

### シーン 4 演出概要 (詳細別セッション)
- カイア (C) 現在対話 → 種を渡す
- 時の窓発動 → 過去ダリオ (D) の屋台 (シーン 3 [3.C] で印象付けた香料商)
- Niro が窓内に入って、ダリオの香料に **能動的に干渉** (倒す / 動かす / 取る等)
- 過去 NPC は気付かない (異物原則)、香料が「ひとりでに動いた」ように見える
- 現在に戻る → カイア畑が変化 (空間的代償)
- 過去側に戻ると、ダリオが商品を失って困っている (代償の発見)
- = Niro が初めて「自分の干渉が遠地に影響を与える」と気付く

## Niro 家の隠し伏線 (第 1 章からのサービス)

### 位置付け
- 動線通りに進めば戻らない (序章 → シーン 1 → 2 → 3 → ...)
- **あえて戻って試してみる** プレイヤー向けの隠し要素
- ちょっとした伏線として、第 4 章メイン演出への前振り

### 演出
- Niro が自分の家に戻る、内部で時の窓発動 (赤=過去 / 青=未来)
- **過去 Niro 家**: 別の家族の気配
  - 家具配置が少し違う
  - 誰かの編み物道具
  - ベッドが別の場所
  - 食器が並んでいる (家族の食卓の名残)
  - **人物は見せない、気配のみ**
- **未来 Niro 家**: 廃墟
  - 砂埃、家具朽ちる、誰もいない
  - 観測者磨耗の最終段階匂わせ

### 設計上の意図
- 第 4 章「Niro 家の過去確認 → 別の家族が住んでいた = 偽記憶設定の確定演出」(STORY_BIBLE §5.3.2) を **弱めない**
- 第 1 章では **気配のみ、はっきり見せない** (好奇心向けサービス)
- 第 4 章で「あの違和感はこれだったのか」と回収

### シーン 3 [3.D] アリア家 (過去親子の温かさ) との対比
- アリア家 = 過去に家族がいた、温かい (確定情報)
- Niro 家 = 過去にも家族がいた **気配** (誰?、不確定)
- → Niro 異物性の伏線、観測者磨耗テーマと連動
