# Stage 4 Progression Building Drafts

Date: 2026-05-08
Branch: `codex/stage4-graphics-foundation-20260508`

## Scope

This pass adds a provisional building batch for content after Chapter 1. The later chapter details are not locked, so the assets deliberately avoid final scene names, puzzle solution language, or character-specific spoilers.

The source inputs were the high-level motifs in `docs/STORY_BIBLE_v1.md` sections 3.3-3.6:

- road / town-exit transition
- field or forest-edge support structure
- central-area workshop / repair structure
- coast / tower vertical landmark

These are authored as reusable Current/Past pairs for scale, density, material, and lighting review. They are not final level-layout commitments.
