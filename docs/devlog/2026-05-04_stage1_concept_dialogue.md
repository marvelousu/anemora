### 議題1: 「壮大」の操作的定義

- AskUserQuestion 1問 (A/B/C/D の選択)
- ユーザー回答: **B (ミニマル密度型)**
- 続いて規模数値を3問並列確認 → うちユーザーは1問は決定 (6-10h)、2問は条件付き回答
- 規模数値合意:
  - プレイ時間: 6-10h
  - マップ: 連結型 4-6 ゾーン (暫定、メカ次第)
  - 主要キャラ: 5-8人
  - 物語スタイル: 空気感主導型 (執筆未経験を AI 補助でカバー)
  - セリフ量: 500-1500行

### 議題2: 革新メカニクス絞り込み (本日最大の議論)

#### Phase A: 6候補一次評価
ユーザーから候補別に詳細フィードバック:
- 候補1 (時間軸×多視点): 古典 RPG 好き、別作品の季節ステージ的「同じ場所が時間軸違いで別の見え方」
- 候補2 (解像度): ドット活かす点で良い線
- 候補3 (建築): スコープ重すぎ、不採用
- 候補4 (絵画): イメージ未確定
- 候補5 (回想): 既視感、不採用
- 候補6 (音響): 環境依存、不採用

#### Phase B: スコープ概念の決定的発言
> ユーザー: 画面の一部領域が、四角い指定した空間の時間軸が切り替わるイメージ。コンピュータの画面のようなUIで、デスクトップでマウスのドラッグアンドドロップしたウィンドウのように、その範囲がスコープになる。絵画はイメージに近い。媒体はゲームのすべてを決める選択肢。

→ 主軸メカは「**領域時間操作**」、媒体は「**世界観に溶け込む1本**」、範囲指定は **プレイヤーが任意サイズで描く** に決定

#### Phase C: ユーザーの軌道修正 (重要)
仮置きを進めようとした Claude にユーザーから明示的フィードバック:
> ユーザー: だから世界観を確定事項にしないでください。そこは広く見て決めましょう。一番大事なところなのです。

→ `feedback_3dpx_no_premature_lockin.md` を memory 化、ブレストモードへ移行

#### Phase D: 軸ブレスト (3軸 × 多候補)
- 軸1 (現代の状態): α-κ の10案
- 軸2 (媒体の正体): ①-⑬ の13案
- 軸3 (時間構造): I-IX の9案

ユーザー反応で残った主候補:
- 軸1: α (廃墟), γ (隠された真実), ζ (再生中ループ), η (地下/地表禁忌), θ (中間時代空白), κ (異世界)
- 軸2: ① (古代遺物), **④ (プレイヤー=超次元存在)**, ⑧ (精霊共生), ⑨ (楽器/詠唱), ⑫ (時の筆/鑿)
- 軸3: I (単線), II (多線), III (円環), IV (樹形), V (層)

#### Phase E: 軸2-④ の発見
> ユーザー: プレイヤーは窓をつくる超次元的な存在。主人公は能力を完知していない。あくまで能力を持つのは主人公でなくプレイヤー側。

→ メタ存在論 + 時間操作の組合せは前例なし、ただし「主人公没入優先」「メタは伏線扱い」がデフォルトと指定

#### Phase F: 7セット提示と絞り込み
A-G の7世界観セットを軸組合せで提示。ユーザー反応:
- A (廃墟継承者): シンプルにあり、ただし「終盤未来分岐解放」は要再考
- B (透明な来訪者): 面白いがプレイヤー関係を主軸にしない
- **C (地下の歌い手)**: 歌い手要素は方向性に合わず不採用、**主人公没入が最重要、世界の謎を探求する物語**
- **D (画工 中間時代埋め)**: 短尺トレイラー映像が浮かぶ
- E (七番目の周回): ループは入れたい
- **F (メタ×廃墟×ループ)**: かなり好み、副線として並走
- G (時計仕掛け鑿): 考えようはある

ユーザー追加要件:
> 雰囲気の参照: 段階開示型残酷ファンタジー・無垢視点アニメ・静謐終末紀行
> 「これまで真実だと思っていたこと」が反転し、世界観が拡張される構造は非常に好き

#### Phase G: v1 統合と確定運命型構造
ユーザー追加発言:
> はじめは過去と未来が見えると思っているが実は違う、大規模戦闘群像漫画のように未来の周回も決まっている、主人公の力 (筆?) でそれを脱却する/変える、というストーリーとか

→ 採用: **Time Frame on a Looping Wasteland** + 多重時間構造 + 5層ベール剥離 + 大規模戦闘群像漫画型確定運命

### 議題3: コアループ3階層

- 1分ループ: 廃墟歩く → 残響察知 → 筆で四角を描く → フレーム展開 → 跨いで踏み込む → 真実断片収集
- 1セッションループ: エリアの残響を順に → フラグメント収集 → ベール一枚剥がれる → 次エリア
- 1ストーリーアーク: 5層構造 (廃墟原因 → 別ループ判明 → 確定運命 → 改変者自覚 → メタ伏線回収 → 介入か受容か)

ユーザー指摘で「違和感のある場所」を「**残響** (前周回・別時代の声・気配・光痕)」という物理現象に置換し動機強化。

### 議題4: The Hook (オープニング3分)

10秒刻みのシーン構成、言葉なしで規模感→主人公→道具→メカ核体験→過去交流→メタ伏線まで段階的に提示。

### 議題5: 差別化軸一文

採用:
> **「終末の廃墟に時の窓を描き、確定された運命の層を旅で一枚ずつ剥がしていく、唯一の HD-2D RPG」**

### 議題6: 比較対象7タイトル

静謐終末紀行 / 段階開示型残酷ファンタジー / 単線知識探索系既存作 / 大規模戦闘群像漫画 / 古典 RPG / メタ構造系既存作 / 無垢視点アニメ
