## 確定事項

### 1. ミア (Resident_F) 設定確定

| 項目 | 内容 |
|---|---|
| 名前 | ミア |
| コード | Resident_F |
| 年齢 | 30-40 |
| 職業 | **元・縫物 / 織物職人** |
| 家族 | **一人暮らし (未亡人 / 独身)** |
| 性格 | 面倒見の良い、世話好き、職人らしい忙しさ |
| 道具 (第 4 章「家の道具」演出) | 針 / 梭 / 紡 / 機械 / はさみ / 糸巻き |

これにより Story Bible §4.3「中央の元職人 (第 4 章で痕跡認識役)」の整合 pending が解決 (handover §14.4)。

### 2. 視界解放メカニズム = 1+5 (陽の角度 + 音の誘導)

旧設計の **南の道土砂封鎖** (序章 [O.E] でミアが片付けた設定) を全削除、視界誘導に統一:

- **時間経過 (1)**: シーン 1 開始 (朝早) → シーン 2 終了 (午前) で陽が一段高くなる、ライティング変更で表現
- **音の誘導 (5)**: 中央広場に戻ると南方面から微かな音 (風 / 鳥 / 遠くの足音)、Zone1AudioController で実装

**旧設計の問題点**:
- ミア (元職人 + 一人暮らし) が朝のうちに土砂を一人で片付けた、という設定の不自然さ
- 序章 [O.E] のミア家方向 = 視界誘導 vs 南方面 = 土砂封鎖、の **非対称** (旧 handover §6)
- 黄昏世界観・「視界が徐々に開ける」表現と相性が悪い

**新設計の利点**:
- ミア家方向 (東) と方法統一
- 黄昏世界観で「時間経過 + 視界解放」は自然演出
- ミアが土砂を片付けた唐突な設定が不要に

### 3. シーン 2 dialogue 設計原則

#### 観測者磨耗の匂わせを 1 回に集約
- 旧版 [2.D] にはミア自身の「物忘れ」言及が 3 連発 (「みんな、何かをよく忘れるようになって」「私も、昨日のお客さんの名前を、思い出せなくて」「不思議よね、覚えていたはずなのに」)
- レト [1.C]「今では、誰も覚えていません」「いずれ何もかもが」と累積で **しつこい伏線** に
- 修正: [2.D] からミア自身の物忘れ言及を全削除、[2.E] のカイアエピソード「家に置いてっちゃって」**1 回のみ** に集約

#### お茶演出削除
- 旧仮: ミアが Niro に「お茶を出す動作」
- 問題: 縫物中なのに作業中断する不自然さ
- 修正: お茶削除、ミアは縫いかけの布をテーブル横に置いて Niro と話す、職人の忙しさ + 親切さ両立

#### 依頼動機 = 縫物の納期
- ミア「私もね、この縫物が今日中で」 ← 家を空けられない理由
- レト [1.G]「もし手があるなら、少し、助けてやってください」と整合

#### Niro 心情の言い換え
- 旧仮: [2.F] Niro 心情「(...あの方)」 ← 「方」が「カタ (人物)」と「ホウ (方角)」の二読み、誤読リスク
- 修正: **「(...道?)」** ← 視界開放の対象 (道) が明確

## v1 final 全文 (6 セクション、約 5 分)

### [2.A] ミア家 アプローチ (約 30-45 秒)
- Niro 心情: "(...煙)" / "(...布、針)"
- 玄関前の職人道具 (はさみ / 布 / 糸巻き) で「物作りの人」と直感伝達

### [2.B] ミア 出会い (約 1 分)
- ミア「あら、見ない顔ね」
- ミア「街に来たばかり?」「私はミア。ここで縫物の仕事をしているの」
- ミア「立ち話もなんだから、寄っていって」 ← 面倒見の良さ表現

### [2.C] ミア家 内部 (約 1.5 分)
- 物理配置: テーブル / 作業場 / 棚 / 暖炉
- Niro 心情調査: 暖炉「(...火)」/ 作業場「(...糸)」/ 棚「(...種?)」/ テーブル「(...縫いかけの布)」

### [2.D] ミアの語り (短縮、お茶削除、約 30 秒)
- ミア「街もね、最近、静かになって」
- ミア「縫いかけのものが、いくつもあってね」
- 縫いかけの布をテーブル横に置いて Niro を椅子に促す

### [2.E] 種の依頼 (約 1 分、簡略化)
- ミア「そういえば」「街と森の境のカイアさん、知ってる?」
- ミア「今朝、種を取りに来たんだけど、家に置いてっちゃって」 ← 観測者磨耗匂わせ 1 回
- ミア「私もね、この縫物が今日中で」「カイアさん、今日中に蒔きたいって言ってたから」
- ミア「届けてくれない?」 ← 簡略化
- インベントリ追加: 種の包み

### [2.F] 出発 (視界解放 1+5、約 30 秒)
- ミア「南へ少し行けば、カイアさんの畑」「気をつけてね」
- 視界解放演出: 陽が一段高くなる + 南方面から微かな音 + 道が陽に照らされて見える
- Niro 心情: "(...陽が)" / **"(...道?)"**
