## 3. Fast VS 実装済 zone (2026-05-18、`FastVsHouseArea` enum)

| zone | 中心座標 (X, 0, Z) | 役割 |
|---|---|---|
| Interior | (-8.35, 0, -8.35) | Niro 家内部 |
| Exterior | ( 8.20, 0,  8.20) | Niro 家外 (玄関 + 外周ロード) |
| CentralPlaza | (20.80, 0, 15.80) | 中央広場 |
| Library | (31.00, 0, 20.00) | 図書館 |

X+ = 東、Z+ = 北。座標上は **Niro 家 (南西) → Exterior (中間) → Plaza (北東寄り) → Library (最北東)** の北東連鎖配置。

### Pad transitions (glow floor pad、5 接続)

| 遷移 | 方位 |
|---|---|
| Interior ↔ Exterior | 玄関 (双方向) |
| Exterior → Plaza | 北東 |
| Plaza → Exterior | 南西 (戻り) |
| Plaza → Library | 北 |
| Library → Plaza | 南 (戻り) |

### Time Window region

42×42 → **78×58 に拡張** (2026-05-18、Library route も V24 生成範囲内)、current/past 同座標。
