## 3. 横断ルール

### 3.1 異物原則
- 異物は Niro のみ
- 全 NPC は「普通の住人」(語り部・前任者・守り人・予言者 役割禁止)
- 過去 NPC (時の窓越し) は Niro に気付かない、独り言は聞こえる

### 3.2 Niro 演出方針
- silent protagonist、自身の違和感は出さない
- 心情は観察的・短い、事実描写中心
- 例: 「(...筆)」「(...本?)」「(...人)」「(...煙)」「(...火)」

### 3.3 過去建物 canon (2026-05-24 確定)
- **基本**: 過去建物は現在と見た目を全部変える (数百〜数千年スパン)
- **例外**: 図書館のような大昔からある建物はそのまま (S1 図書館 = 不変)
- **内部仕様**: 家の中でも時の窓を使える → 過去の同プロットにも建物が建っている前提。**サイズ・形・入れる構造は近い** (interior 使い回し許容)、見た目 (外装・内装の様式) は別時代
- マップ図 (PPTX slide 9-14) の再描画は user 担当 (canon 確定したので段階反映)

### 3.4 観測者磨耗の伏線配置 (累積でしつこくしない)
- **S1 [1.C]** レト「今では、誰も覚えていません」「いずれ何もかもが」(台詞・surface)
- **S2 [2.E]** ミア「家に置いてっちゃって」(台詞・1 回・surface な磨耗匂わせ)
- **S5 [5.B]** 家計簿 (物・任意・深い、前半温かく詳細、後半文字薄れて白紙) ← 真層 payoff の物理化
- **S3 [3.D]** アリア「……いつか、わたしも」(来ない未来の柔らかい伏線、テーマ単独)

### 3.5 時の窓 仕様 v3.2 + S4 例外
- 通常: プレイヤーが時の筆で自由発動 (赤=過去、1 周目は赤のみ)
- 例外: 章クライマックス・特別な瞬間ではオート発動 ([4.D]/[4.G])
- 屋外範囲指定 / 建物内部範囲指定 の両モード

### 3.6 player-facing 禁止語
- 「層」「ベール剥離」「観測者磨耗」(設計用便宜語、UI/dialogue 不可)
- 固有名詞 (Antela 等) も UI/dialogue で前面化しない

### 3.7 セリフ予算
- 1 章 = 500-1500 行、空気感主導

### 6.2 [1.E] 過去図書館 canon (v2.0)

過去図書館 = **古層建物、現在と同じ建物** (過去建物 canon の例外)、機能していた時代を映す。

Niro 観察 3 行 (canonical、変更不可):
```
Niro「(...人)」               ← 人の存在に気付く (意図演出、汎用 placeholder ではない)
  (pause 1.35s)
Niro「(...本を読んでいる)」
  (pause 1.05s)
Niro「(...こちらには気づいていない)」
```

人物は遠景、Niro に気付かない (異物原則)。独り言・命名・話者「アリア」は付与しない。

## 10. S5 廃墟エリア (v1.1)

### 10.1 S5 全体ルール
- 1 章のパズル要素ショーケース (B 軸 = 時の窓パズル)
- パズルは 1 章既存メカ (時の窓: 描く・入る・観察・触れる/取る) のみ。2 章以降ギミック化の base form
- 案 1「棲み分け」: 必須パズル (橋) と任意おまけ (過去でのみ入れる家) の役割分離
- メカ双方向性の明示: シーン 1 (過去→現在) ↔ シーン 5 (現在→過去)

### 10.2 時の窓の物理ルール (本設計の前提)
- 窓が開いている間、窓内 = 過去。Niro は窓内の過去地形を歩ける (Fast VS 実証済)
- 窓内 (過去の橋上) で窓が閉じると現在座標 (崩落) に戻される = 落ちる。**渡り切ってから閉じる**
- 中継の橋脚は **現在でも崩れず残存** → 窓を閉じても安全に立てる (2 ホップ成立の根拠)

### 10.3 流れ ([5.A]-[5.E]、約 5-7 分)

**[5.A] 廃墟エリア入口 (約 30-45 秒)**
- 場所: カイアの農園から東 → 廃墟エリア入口
- 演出: 抜け殻の建物が点在、崩れた壁、廃材が転がる、蔓、静寂、午後の傾いた陽
- Niro 心情:「(...誰も、いない)」/「(...崩れて)」
- 移動制限: 西=カイアの農園戻れる、東=探索エリア

**[5.B] ちょっとした探索 + 伏線 (約 1-2 分)**
- 自由に動ける廃墟。崩れた建物、打ち捨てられた廃材
- **過去でのみ入れる家を数軒 (2-3)**: 現在は崩落/封鎖、過去に時の窓を開けると入れる (任意)
  - **大半は mundane なデコイ** — 整ったテーブル・食器・子供の玩具・畳まれた毛布・鍋・道具。「家族が住んでいた」温かい情感レイヤー、現在の崩落との対比
  - **1 軒 (F5) に伏線アイテム「暮らしの記録」(家計簿)** — 前半〜中盤は温かく詳細 (買い物・子供の成長・収穫・小さな出来事)、後半は文字がだんだん薄くなり、やがて白紙 (破れも焼けもない、ただ薄れて無くなる)
  - 見た目は普通の帳面。手に取って/調べて初めて後半の白紙に気付く
  - Niro 観察:「(...暮らしの、記録)」→「(...だんだん、薄く)」→「(...何も、書かれていない)」
- F4 = 現在も過去も入れる、意味なし decoy (red herring)
- F2/F3 = 過去のみ、デコイ (例: F2=子供がいた家 / F3=老人の家、差をつける)
- F5 = 過去のみ、家計簿伏線

**[5.C] 進路の障害 (約 30 秒)**
- 東への道 = 涸れた谷に架かる崩れた大橋 (HD-2D らしいリアル調の本格的な石橋/アーチ橋、橋桁は地面より高所)
- 廃墟エリアの一部、かつて Antela 東縁を繋いでいた橋。現在は崩落、渡れない
- Niro 心情:「(...道が、崩れて)」/「(...大きな、橋)」

**[5.D] パズル: 崩れた大橋を渡る (約 3-4 分)**
- 時の窓 (赤=過去) を開く → 過去の橋が現れる、**修繕中** — 完成し使われていた橋の一区画が傷み、職人が直している。渡るのを待つ町の人数名 (橋の向こうへ通う日常、修繕を待っている)
- **ホップ 1**: 窓が橋全体に届かない → 過去の橋の手前半分を窓で甦らせ、窓内を歩いて中継の橋脚 (現在も残存) まで渡る = 「窓内を歩いて渡れる」を学ぶ
- 中継の橋脚で窓を開け直す → **ホップ 2** (奥半分) = 「窓 1 枚では届かない」気づき
- ホップ 2 の奥半分に **修繕中の傷んだ切れ目** → 行き止まり
- 発想: 現在の廃墟は廃材 (石材) が豊富 (橋脚上にも崩落石材あり、backtrack 不要) → 現在の石を取り、過去の窓へ持ち込み、傷んだ切れ目に嵌める = **シーン 1 の逆 (現在→過去)**
- 過去の橋が繋がる → 渡り切る
- Niro 心情 (draft):「(...修繕、途中)」/「(...向こうから、石を)」/「(...渡れる)」

**[5.E] 橋の先 → シーン 6 への接続 (約 30 秒)**
- 橋を渡り切った先も **シーン 5 と同じ廃墟エリアのマップ** — ちょっとした廃墟空間が続く (別マップではない)
- 視覚誘導: 東に続く道、夕焼けの色が差し始める
- Niro 心情:「(...まだ、奥に)」
- 進行: 廃墟エリアマップの右端から右のマップへ進むとシーン 6 の自動アニメーションが始まる (シーン 6 = 別マップ、2D 真横視点・夕焼け)
